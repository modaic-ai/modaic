## What is a Program?

The hardest part about using language models to mimic judgment-heavy decision-making is that **they don't know when they don't know.** Modaic uses the latest in **mechanistic interpretability** to get highly calibrated confidence scores for each prediction an LM makes. Some tasks you can use a Program for are.

- **Subjective Rating**: _"Rate this AI response on a scale of 1-5"_
- **Binary Classification**: _"Determine the relevance of this article for my research on polar bears"_
- **Multi-Class Classification**: _"Determine the content risk level: safe, mild, moderate, or severe"_
- **Multi-Label Classification**: _"Extract the user intent, tone, and topic from this support message"_
- **Triage + Routing**: _"Determine if this user message requires a human response, an AI response, or no response"_
- **Content Moderation**: _"Given a message in a Discord channel, determine if it's relevant to the channel or not"_

## Create a Program

#### Using the Modaic SDK

Install the Modaic SDK and create your program locally — in Python or TypeScript.

First, install the SDK:

<CodeGroup>
```bash python
uv add modaic
```

```bash typescript
npm add modaic zod
```

</CodeGroup>

Then, create your Program:

<Info>

<CodeGroup>
```python python
import dspy
import modaic

class CodeCompletionSignature(dspy.Signature):
    """Given a prompt and a code completion in luau, Roblox's scripting language,
    evaluate the quality and relevance of the code completion in relation to the prompt.
    """

    prompt: str = dspy.InputField(desc="The prompt used to generate the code completion")
    completion: str = dspy.InputField(desc="The code completion to evaluate")
    quality: modaic.Scale[1, 4] = dspy.OutputField(desc="The quality of the completion (1-4)")


if __name__ == "__main__":
    code_completion_program = modaic.Predict(
        CodeCompletionSignature,
        lm=dspy.LM(model="modaic/openai/gpt-oss-120b"),
    ).as_arbiter()

    code_completion_program.push_to_hub("roblox/code-completions")
```

```typescript typescript
import { Arbiter, Signature, Scale } from "modaic";
import { z } from "zod";

const signature = new Signature({
  instructions:
    "Given a prompt and a code completion in luau, Roblox's scripting language, evaluate the quality and relevance of the code completion in relation to the prompt.",
  input: z.object({
    prompt: z.string().describe("The prompt used to generate the code completion"),
    completion: z.string().describe("The code completion to evaluate"),
  }),
  output: z.object({
    quality: Scale(1, 4).describe("The quality of the completion (1-4)"),
  }),
});

await Arbiter.create({
  repo: "roblox/code-completions",
  signature,
  model: "modaic/openai/gpt-oss-120b",
});
```

</CodeGroup>

## Running your Program

Once your program is pushed to modaic hub you can run it via Modaic's API.

<CodeGroup>
```python python
from modaic import Arbiter

# Load the program from the same repo you pushed it to
code_completion_program = Arbiter("roblox/code-completions")

# Call your program, kwargs should match the fields you declared in the dspy.Signature
result = code_completion_program(prompt="Print hello world", completion="print('Hello World')")

# Access the output
quality = result.output.quality

print("Quality:", quality)
```

```typescript typescript
import { Arbiter } from "modaic";

// Load the program from the same repo you pushed it to
const code_completion_program = new Arbiter("roblox/code-completions");

// Call your program — keys should match the fields you declared in the Signature
const result = await code_completion_program.predict({
  prompt: "Print hello world",
  completion: "print('Hello World')",
});

console.log("Quality:", result.output?.quality);
```

```bash curl
curl -X POST https://api.modaic.dev/api/v1/arbiters/predictions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $MODAIC_TOKEN" \
  -d '{
    "input": {
      "prompt": "Print hello world",
      "completion": "print(\"Hello World\")"
    },
    "arbiters": [
      {
        "arbiter_repo": "roblox/code-completions",
      }
    ]
  }'
```
